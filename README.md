Glow & Beauty — интернет-магазин косметики
Дипломный учебный проект на Python и Django. Сайт позволяет просматривать каталог косметики, искать товары, добавлять товары в корзину и оформлять заказ.
Проект предназначен для локального запуска и демонстрации. Оплата в нём не подключена: заказ сохраняется в базе данных как заявка.
Возможности
Каталог косметики с фотографиями, ценами и категориями.
Поиск товаров по названию, бренду и описанию.
Страница с подробной информацией о товаре и составе.
Регистрация, вход и выход пользователя.
Персональная корзина: добавление и удаление товаров.
Оформление заказа с контактными данными и адресом доставки.
Админ-панель Django для управления товарами, категориями и заказами.
Адаптивный интерфейс на Bootstrap 5.
Технологии
Python 3.10 или новее
Django 5.x
SQLite
Pillow — загрузка изображений товаров
Bootstrap 5 (подключается через CDN)
Требования
Установите Python. При установке в Windows отметьте пункт Add Python to PATH. Проверить установку можно командами:
python --version
pip --version
Установка и запуск на Windows
Откройте PowerShell или терминал VS Code в папке проекта, где находится manage.py. Если папки проекта ещё нет, сначала перейдите в папку, куда хотите его установить.
1. Создайте виртуальное окружение
python -m venv venv
2. Активируйте его
Для PowerShell:
.\venv\Scripts\Activate.ps1
Для командной строки CMD:
venv\Scripts\activate.bat
После активации в начале строки терминала появится (venv). Если PowerShell запрещает запуск скрипта, выполните команду ниже от имени текущего пользователя, затем повторите активацию:
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
3. Установите зависимости
Если в проекте есть requirements.txt:
pip install -r requirements.txt
Если файла пока нет:
pip install "Django>=5.0,<6.0" "Pillow>=10.0"
Чтобы записать установленные зависимости в requirements.txt:
pip freeze > requirements.txt
4. Проверьте расположение manage.py
Выполните:
dir
В выводе должен быть manage.py. Если файла нет, значит, терминал открыт не в корневой папке проекта. Перейдите в нужную папку командой cd, например:
cd C:\Users\ВашеИмя\Desktop\cosmetics_shop
5. Создайте и заполните базу данных
Из папки с manage.py выполните:
python manage.py makemigrations shop
python manage.py migrate
makemigrations создаёт файлы миграций по моделям приложения shop. migrate применяет их и создаёт таблицы в локальной базе SQLite (db.sqlite3). Повторно выполнять makemigrations без изменений моделей обычно не нужно; migrate можно запускать после новых миграций.
6. Создайте администратора
python manage.py createsuperuser
Введите имя пользователя, email (если запросят) и пароль. При вводе пароль в терминале не отображается — это нормально.
7. Запустите сайт
python manage.py runserver
Откройте в браузере:
Сайт: http://127.0.0.1:8000/
Панель администратора: http://127.0.0.1:8000/admin/
Остановить сервер можно сочетанием Ctrl+C в терминале.
Первоначальное заполнение магазина
Откройте /admin/ и войдите под созданным суперпользователем.
Добавьте несколько категорий, например «Уход за лицом», «Макияж», «Волосы».
Для каждой категории укажите уникальный slug латиницей и через дефисы, например face-care.
Добавьте товары. Укажите название, уникальный slug, бренд, цену, остаток, описание и категорию. Фотография необязательна.
Вернитесь на главную страницу каталога.
Зарегистрируйте обычного пользователя или войдите в существующий аккаунт, чтобы проверить корзину и оформление заказа.
Изображения и загружаемые файлы
Загруженные фотографии сохраняются в папке media/. В режиме разработки Django раздаёт их согласно настройкам MEDIA_URL и MEDIA_ROOT в config/settings.py и маршрутам в config/urls.py.
Папку media/ обычно не добавляют в Git: это пользовательские загрузки, а не исходный код. Для демонстрации на другом компьютере изображения нужно загрузить заново.
Основные адреса сайта
URL	Название (Name)	Описание
/	shop:home	Главная промо-страница (Landing)
/products/	shop:product_list	Каталог всех доступных товаров
/category/<slug>/	shop:product_list_by_category	Товары выбранной категории
/product/<slug>/	shop:product_detail	Страница товара (описание, состав)
/cart/	shop:cart_detail	Просмотр корзины покупок
/cart/add/<id>/	shop:add_to_cart	Добавление товара в корзину
/checkout/	shop:checkout	Форма оформления заказа
/login/	login	Авторизация пользователя
/register/	shop:register	Регистрация нового покупателя
/admin/	—	Панель администратора(логин: admin, пароль:admin1)
