# 🖤 GLOW & BEAUTY — Luxury Cosmetics Marketplace (Дипломный проект)

Полнофункциональный e-commerce маркетплейс премиальной косметики на **Python 3.14** и **Django 5.x** с эксклюзивным темным дизайном (**Dark Edition**), разделением ролей (Покупатель / Продавец / Администратор), живым трекингом заказов, системой подарочных сертификатов и выгрузкой аналитики.

---

## 🌟 Ключевой функционал проекта

### 🛍️ Для Покупателя:
1. **Витрина и промо-лендинг (`/`):** Hero-баннер, УТП магазина, динамический блок новинок.
2. **Продвинутый каталог (`/products/`):**
   * Фильтрация по категориям.
   * Фильтр по диапазону цен (от / до рублей).
   * Чекбокс «Только в наличии».
   * Сортировка: *Сначала новые*, *Сначала дешевле*, *Сначала дороже*, *По названию (А-Я)*.
   * Полнотекстовый поиск по бренду, названию, описанию и составу.
   * Бейджи срочности: `🔥 Осталось X шт.!` при остатке на складе $\le 3$.
3. **Список «Избранное» (Wishlist, `/wishlist/`):**
   * Добавление/удаление товаров в один клик по сердечку `🤍` / `❤️`.
   * Отдельная страница отложенных товаров без захламления корзины.
4. **Карточка товара (`/product/<slug>/`):**
   * Фото высокого разрешения, цена, складской остаток, бренд и состав (INCI).
   * **Модуль отзывов и оценок:** покупатели могут оставлять текстовые отзывы с оценкой от 1 до 5 звёзд, система автоматически пересчитывает средний рейтинг товара.
5. **Корзина и Чекаут (`/cart/`, `/checkout/`):**
   * Контроль остатков на складе при добавлении и оформлении.
   * **Оплата подарочной картой:** поле ввода промокода на этапе оформления заказа, автоматический перерасчет итоговой суммы за вычетом номинала карты.
   * Списание остатков со склада внутри атомарной транзакции (`transaction.atomic`).
6. **Отслеживание заказов (Order Tracking, `/my-orders/`, `/track/<id>/`):**
   * Интерактивный прогресс-бар доставки (4 этапа: *Оформлен* ➔ *Собирается* ➔ *В пути* ➔ *Доставлен*).
   * Подробный состав посылки и данные доставки.
7. **Товарный чек для печати и PDF (`/order/<id>/invoice/`):**
   * Готовая к печати страница товарного чека (`window.print()`) со стилями `@media print`.
8. **Подарочные сертификаты (`/gift-card/`, `/gift-card/use/`):**
   * Покупка карт номиналом 1 000, 3 000, 5 000, 10 000 ₽ с генерацией защищенного кода вида `GB-XXXXXXXX`.
   * Страница быстрой проверки активности и баланса карты.

---

### 💼 Для Продавца (Vendor Dashboard, `/seller/dashboard/`):
* **Защита доступа:** декоратор `@user_passes_test(is_seller_check)` блокирует доступ обычным покупателям (вход разрешен только персоналу `is_staff=True` и администраторам).
* **Финансовая аналитика:** карточки с суммарной выручкой от продаж и количеством проданных единиц товара.
* **Управление заказами:** продавец видит только заказы, в которых куплены его товары, и может прямо из таблицы менять статус доставки (*Оформлен* ➔ *Собирается* ➔ *В пути* ➔ *Доставлен*).
* **Публикация товаров (`/seller/add-product/`):** веб-форма с загрузкой фото, выбором категории и автогенерацией уникального slug.
* **Экспорт в Excel (`/seller/export-csv/`):** генерация на лету и выгрузка отчета о продажах в файл `.csv` с кодировкой UTF-8-BOM (корректно открывается в Microsoft Excel).

---

### ⚙️ Для Администратора (`/admin/`):
* Полная кастомизация админки Django: inline-таблицы позиций заказа (`OrderItemInline`), фильтры по датам, статусам, категориям, поиск по клиентам и предзаполнение slug.

---

## 🛠 Технологический стек

* **Backend:** Python 3.14+, Django 5.x (ORM, Class-based views, User Auth, Transactions).
* **Database:** SQLite3 (в разработке), поддержка PostgreSQL.
* **Media Handling:** Pillow (обработка и валидация изображений).
* **Frontend:** HTML5, CSS3, Bootstrap 5, Google Fonts (*Outfit* + *Plus Jakarta Sans*).
* **Архитектура:** MTV (Model-Template-View) с разграничением бизнес-логики и прав доступа на основе RBAC (Role-Based Access Control).

## 🚀 Пошаговая инструкция по запуску проекта

### 1. Открытие проекта в терминале
Откройте PowerShell / терминал VS Code в папке с файлом `manage.py`:
```powershell
dir
```
*(Убедитесь, что в выводе присутствует `manage.py`).*

### 2. Активация виртуального окружения
```powershell
# Windows PowerShell
.\venv\Scripts\Activate.ps1

# Windows CMD
venv\Scripts\activate.bat

# macOS / Linux
source venv/bin/activate
```
*(В начале строки терминала появится `(venv)`).*

### 3. Установка зависимостей
```powershell
pip install -r requirements.txt
```
*(Если requirements.txt отсутствует: `pip install Django Pillow`)*

### 4. Применение миграций базы данных
```powershell
python manage.py makemigrations shop
python manage.py migrate
```

### 5. Создание учетной записи Администратора
```powershell
python manage.py createsuperuser
```
*(Укажите логин, email и надежный пароль).*

### 6. Запуск сервера разработки
```powershell
python manage.py runserver
```

## 🧑‍🏫 Чек-лист для успешной защиты диплома

Во время демонстрации комиссии рекомендуется идти по следующему сценарию:
1. **Дизайн и UI/UX:** продемонстрировать глубокую черную тему (**Dark Edition**), типографику *Outfit*, адаптивность под экраны и микроанимации кнопок.
2. **Каталог и фильтрация:** показать работу фильтра цен, флаг «Только в наличии» и переключение сортировок (дешевле/дороже).
3. **Социальное подтверждение:** открыть товар, показать средний рейтинг и блок реальных отзывов с оценками от 1 до 5 звёзд.
4. **Вишлист:** нажать на сердечко у товара, затем открыть страницу «❤️ Избранное».
5. **Подарочная карта и покупка:** купить карту на 3 000 ₽, скопировать код вида `GB-XXXXXXXX`, перейти в корзину к оформлению заказа и ввести код — показать комиссии, как итоговая сумма уменьшилась на номинал карты.
6. **Трекинг доставки:** открыть оформленный заказ и показать живой прогресс-бар этапов доставки.
7. **Документооборот:** нажать кнопку «📄 Распечатать товарный чек» и показать готовый инвойс с диалогом сохранения в PDF.
8. **Кабинет продавца:** войти под аккаунтом со статусом Staff, показать аналитику выручки, список только своих товаров, изменить статус заказа покупателя на «В пути» и нажать кнопку **«📊 Экспорт в Excel»**, продемонстрировав скачивание отчета о продажах.
9. **Безопасность:** показать, что при попытке зайти в `/seller/dashboard/` под обычным покупателем система блокирует доступ.
